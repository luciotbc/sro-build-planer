01 — FOUNDATION

Setup & tokens

One CSS entrypoint. The @theme block defines design tokens that Tailwind compiles into utilities — so bg-card, text-brass and rounded-panel all just work.

rails/app/assets/stylesheets/application.tailwind.css 
/* =============================================================================
   SRO Lab — Design System tokens (Tailwind v4, CSS-first)
   Import this as your single Tailwind entrypoint. Every token below becomes a
   utility: --color-brass → bg-brass / text-brass / border-brass, etc.
   ============================================================================= */

@import "tailwindcss";

/* Pull Inter in (or self-host via @font-face for production). */
@import url("https://rsms.me/inter/inter.css");

@theme {
  /* ── Surfaces ─────────────────────────────────────────────────────────── */
  --color-bg:        #0c0e12;   /* app background            → bg-bg          */
  --color-card:      #15181f;   /* default panel             → bg-card        */
  --color-card-hi:   #1c2029;   /* raised panel / inset      → bg-card-hi     */
  --color-line:      #262a33;   /* hairline borders          → border-line    */

  /* ── Text ─────────────────────────────────────────────────────────────── */
  --color-text:      #e6e8ec;   /* primary copy              → text-text      */
  --color-text-dim:  #8b919e;   /* secondary / labels        → text-text-dim  */
  --color-text-mute: #5c6270;   /* tertiary / disabled       → text-text-mute */

  /* ── Brand (brass) ────────────────────────────────────────────────────── */
  --color-brass:     #d4a847;   /* primary accent            → text-brass     */
  --color-brass-hi:  #f4d878;   /* highlight / planned value → text-brass-hi  */

  /* ── Semantic ─────────────────────────────────────────────────────────── */
  --color-blue:      #4ea3ff;
  --color-red:       #e85a4a;   /* destructive / decrease    */
  --color-green:     #38b676;   /* positive delta / increase */

  /* ── Radius ───────────────────────────────────────────────────────────── */
  --radius-field:    10px;      /* inputs, small buttons     → rounded-field  */
  --radius-control:  12px;      /* step buttons, chips       → rounded-control*/
  --radius-tab:      14px;      /* tab wells, identity bar   → rounded-tab     */
  --radius-panel:    18px;      /* cards, modals, drawers    → rounded-panel   */

  /* ── Type family ──────────────────────────────────────────────────────── */
  --font-sans: "Inter", system-ui, -apple-system, "Segoe UI", sans-serif;

  /* ── Min hit target (touch) ───────────────────────────────────────────── */
  --spacing-tap: 44px;          /* min-h-tap / w-tap                          */
}

/* App-level base: the radial backdrop both screens share. */
@layer base {
  html, body {
    background: var(--color-bg);
    color: var(--color-text);
    font-family: var(--font-sans);
    -webkit-font-smoothing: antialiased;
  }

    min-height: 100vh;
    background:
      radial-gradient(1200px 800px at 50% -10%, #1a1d24 0%, #0c0e12 60%);
  }
  /* Tabular numerals everywhere we show levels / points. */
  .tnum { font-variant-numeric: tabular-nums; }
}

/* =============================================================================
   Component shorthands (@utility) — optional sugar so partials stay readable.
   Each is just the utility recipe captured once; use them or inline the classes.
   ============================================================================= */

@utility btn-primary {
  @apply inline-flex items-center justify-center rounded-field min-h-tap px-4 py-[9px]
         text-[13px] font-extrabold tracking-[0.2px] text-bg cursor-pointer
         bg-gradient-to-b from-brass-hi to-brass;
}
@utility btn-ghost {
  @apply inline-flex items-center justify-center rounded-field min-h-tap px-4 py-[9px]

         bg-card border border-line hover:bg-card-hi;
}

     primary: "btn-primary",
     ghost:   "btn-ghost",

import { Controller } from "@hotwired/stimulus"

// Connects to data-controller="dialog"
// Thin wrapper over the native <dialog> element. Powers shared/modal,
// shared/drawer and shared/sheet — backdrop click, Esc and focus-trap are
// native; this just opens/closes and stops backdrop bubbling.
//
//   connect()        — showModal() if you want it open on render
//   open()           — el.showModal()
//   close()          — el.close()  (CSS exit animation can run before remove)
//   backdropClose(e) — close when the click target IS the <dialog> (the backdrop)
//   stop(e)          — e.stopPropagation() on the inner panel
//
// Turbo tip: render the dialog inside <turbo-frame id="modal"> and call
// open() on turbo:frame-load so a server response pops the editor automatically.
export default class extends Controller {
  open()  { /* this.element.showModal() */ }
  close() { /* this.element.close() */ }
  backdropClose(event) { /* if (event.target === this.element) this.close() */ }
  stop(event) { /* event.stopPropagation() */ }
}

Hotwire — Turbo Frame & Stream

Two end-to-end recipes: the editor pops in a lazy <turbo-frame> modal, and stepper changes broadcast a Turbo Stream that swaps the skill row + recomputes the summary totals — no reload.

<%#
  HOTWIRE PATTERN — live "current → planned" stat updates via Turbo Stream
  ===========================================================================
  When the stepper PATCHes a skill level, the controller replies with this
  Turbo Stream. It swaps the single skill row AND re-renders the summary totals

    def update

      @skill.update!(level: params[:level])

      respond_to do |format|
        format.turbo_stream                       # → this template
        format.html { redirect_to character_path(current_character) }
      end
    end
