01 — FOUNDATION

Setup & tokens

One CSS entrypoint. The @theme block defines design tokens that Tailwind compiles into utilities — so bg-card, text-brass and rounded-panel all just work.

rails/app/assets/stylesheets/application.tailwind.css
i Why CSS-first? Tailwind 4 reads tokens from @theme rather than a JS config. Keeping the original --color-* names means existing inline var(--brass) references keep resolving during migration.

09 — COMPONENT

Stat rows

The signature pattern: white current + green delta = brass planned. Stack several in a divided card; each row is the unit a Turbo Stream re-renders.

Mastery total 210+230=440
Required level 92+18=110

13 — PATTERNS

Hotwire — Turbo Frame & Stream

Two end-to-end recipes: the editor pops in a lazy <turbo-frame> modal, and stepper changes broadcast a Turbo Stream that swaps the skill row + recomputes the summary totals — no reload.

rails/app/views/hotwire/turbo_frame_modal.html.erb
↳ Flow: Edit Planned link targets #modal → controller renders the <dialog> partial inside the frame → dialog#open fires on frame load. A + tap PATCHes, the server replies with the stream above, and #plan_summary re-renders in place.
